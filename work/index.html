1. アクセサリー

アクセサリーブランド「IVY（アイビー）」の作品づくりを支える仕事です。

作業の流れ

クリスタルガラスのビーズ仕分け → パーツ組み → 検品 → 梱包。作品の撮影から学ぶこともできます。

はじめての人へ

週1回、作家を講師に招くアクセサリー教室を開いています。将来、アクセサリーの仕事を自分でしたい人の支援もしています。

できあがるもの

ピアス・イヤリングなどの商品です。マルシェで販売しています（IVYのページ）。

2. 農園・食

薩摩川内市祁答院の農園と組んでやる仕事です。相手は同じグループの合同会社猪ノ屋です。

作業の流れ

猪ノ屋玄米（長岡式酵素玄米）の選別・移し替え → パッケージ。規格外野菜の仕分けもあります。ラボ1階の花壇での栽培も準備中です。

できあがるもの

パッケージされた玄米は、マルシェなどで販売されます。くわしくは農福連携の取り組みをご覧ください。

3. 販売・マルシェ

毎月1回の「Uriboマルシェ」のほか、県内各地のマルシェにアクセサリーブランド「IVY」として出店し、自分たちの商品をお客さんに直接売ります。ナウル政府観光協力店として、缶バッジなどのグッズも売っています。

向いている人

接客が好きな人、外に出たい人、人と話すのが得意な人。

4. デジタル・企画

SNS投稿、チラシ作成、商品企画、売上記録などです。ラボ発のスマホ見守りサービス「あのね」や、服薬支援システム「のんだっけ？」の開発にも関われます。

向いている人

パソコンが好きな人、アイデアを出すのが得意な人。

「デジタル」の考え方は「DX特化型・事業創出型」とはで説明しています。

ある日のうりぼラボ

年中無休で開所しています。午前のみ、午後のみの通所も相談できます。

  1. 10:00出勤・体調チェック・今日の作業を相談
  2. 10:15午前の作業アクセサリー／農園／企画など
  3. 12:00昼休み軽食は自己負担200円（400円相当の軽食に、施設補助200円）。お弁当の持参もできます。
  4. 13:00午後の作業・マルシェ準備
  5. 14:30片付け・日報・明日の予定
  6. 15:00退勤

出退勤の時間は固定していません（フレックスタイム）。9:45〜14:45の間で、体調に合わせて出退勤できます。送迎は鹿児島駅とうりぼラボの間を、通所時間に合わせて1時間おきに走ります。鹿児島市内のその他のルートはご相談ください。

自分に合う作業の見つけ方

作業は、本人の希望と体調、得意なことを聞いて、相談しながら決めます。全員が全部の作業をするわけではありません。

見学や体験利用で、実際の作業を見たり、試したりできます。合うかどうか、ゆっくり確かめてください。通う日数や時間、在宅作業の相談も、見学のときにお話しください。

# 取材記事（INOVISION）の置き場と、載せる前の条件

作成日：2026年11月15日／対象：urilabo.com の専用ページに併設する取材記事

このファイルは作業用のメモです。docs/ の中にあるので、サイトには公開されません。

## いまの状態

2026年11月15日の時点で、専用ページに併設する取材記事の原稿はありません。そのため、記事のページは作っていません。中身のないページを先に公開すると、検索で薄いページとして扱われるためです。

## 置き場

| 項目 | 決めたこと | 状態 |
|---|---|---|

本体ページに足す1行は、次の形にします。URL と題は記事が決まってから入れます。

```html
<a href="（記事のURL）" target="_blank" rel="noopener">（記事の題）<span>INOVISION（当グループの媒体）による取材記事</span></a>
```

## 記事の冒頭に必ず入れる一文

記事の最初の段落の前に、次の一文を入れます。第三者が評価した記事に見えないようにするためです。

> この記事は、うりぼラボと同じ HOUSE OF INOYA グループの媒体「INOVISION」が取材して書きました。

## 載せる前に確かめること

1. 記事に出る人の名前、写真、発言について、本人の同意の記録がある。必要な場合は家族の同意もある。
2. 同意の記録が見つからない人は、名前も写真も発言も載せない。本人が特定できる書き方もしない。
3. 本体ページと同じ文を使っていない。事実（定員、工賃、住所、電話、営業日、送迎）の数字は本体ページと同じにする。
4. 人が写る写真は、藤原さんの確認が済んでいる。
5. 公開は、藤原さんの確認のあとに行う。
